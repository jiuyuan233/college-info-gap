# 大学生信息差 · College Info Gap

> **破除信息差**：大学里那些「不主动搜、没人告诉你,等知道时已经晚了」的关键信息,都在这里。

## 这是什么

一个面向中国大学生的**公共知识库**。

很多改变命运的信息陌生人不会主动告诉你——保研的门道、奖学金申请的技巧、竞赛的性价比、找实习的渠道、教育优惠的羊毛、培训贷的套路……等你踩过坑才知道,已经付出了代价。

这里收集、整理、持续更新这些信息,让**不认识大佬的同学也能站在同样的信息起跑线上**。

## 每条信息三要素

收录的信息必须包含:

1. **来源**——官方链接优先,杜绝「我听说」
2. **适用范围**——年级 / 专业 / 地区 / 学校类型
3. **时效**——政策每年都在变,注明更新时间和软截止日期

## 如何贡献

- **补充信息**:直接提 Pull Request,参考 [docs/_template.md](docs/_template.md) 的格式
- **纠错更新**:政策变了、链接失效了,开 Issue 或直接 PR
- **禁水内容**:拒绝广告、培训机构软文、无来源传言

完整贡献规范见 [CONTRIBUTING.md](CONTRIBUTING.md)。
