# 00 · 权威信息源清单

> **适用**:全体与大一新生(为刚入学的同学首选这份,再去看各板块)
> **核实时间**:2026-10(表内域名全部实测可访问)

先立一条规矩:**这个仓库只登一手来源**。一手 = 政府/学校/主办方的官网与官方系统;营销号、代报名、培训班都不是。网上看到任何「信息」第一件事是回溯到这个清单里找到的官方原文。

## 可信度分级

| 等级 | 含义 | 场景 |
|---|---|---|
| S | 部委/全国性官方系统 | 政策、全国考试、学籍 |
| A | 省级考试院/本校教务处 | 时间在同校差异大,以这里为准 |
| B | 主办方官网 | 竞赛、奖学金具体申报 |
| C | 商业平台/社区 | 找灵感、攒技巧,**不作为最终依据** |

## A 级:本校渠道(最容易被忽视)

1. **教务处官网** + 教务系统:选课、成绩单、推免细则、转专业文件
2. **学院官网「通知公告」栏**:保研细则、评奖评优公告,比教务处消息更细更快
3. **图书馆官网**:数据库入口、 VPN、文献传递与查重次数
4. **资助/学工系统**:奖助学金申请都在里面,学期开始先看一遍
5. **辅导员**:在官方文件没说清的地方,要求辅导员出具文件或书面答复

## 大一新生「开学 10 件事」清单

按顺序做,一周搞定,沿用到毕业:

1. ✅ 注册学信网并**核对学籍信息**
2. ✅ 激活学校邮箱 + 教务系统账号
3. ✅ 关注学院官网「通知公告」栏 RSS/收藏
4. ✅ 查本校《学生手册》(奖学金细则、处分规定都在里面)
5. ✅ 图书馆官网注册账号,试一次文献数据库检索
6. ✅ 抢第一学期四六级报名(名额有限,学校另发通知)
7. ✅ 12306 完成学生票核验
8. ✅ 申请 GitHub Student Pack(如果有写代码需求)
9. ✅ 下载「国家反诈中心」App 并开启预警
10. ✅ 把这份清单发给一个刚认识的同班同学,互相提醒

## 快速定位「某高校某份官方文件」的检索公式

```
site:edu.cn 学校名 关键词 filetype:pdf
```

例:查 A 大保研细则 → `site:edu.cn A大学 推免 细则 filetype:pdf`
查不到时:回学院官网「通知公示」栏目翻近 3 年,或让辅导员提供书面文件。
