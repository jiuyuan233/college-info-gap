# 01 · 学业规划

> **适用**:全国本科学生(部分政策因校而异,以本校教务处为准)
> **核实时间**:2026-10

绩点和规划,决定你大学四年「攒下了多少选择权」。这些规则没人上课讲,但每个都影响保研、出国、求职。

## 绩点(GPA)为什么是硬通货

- **保研**看绩点排名(通常要求专业前 10%~25%,越高越好)
- **出国**看 GPA + 托福/雅思 + 科研实习
- **名企校招**筛选简历时,绩点排名是常有的一道筛选项
- 绩点丢了没法挽回,考研失利后想就业时排名就成了软肋

**建议**:入学第一周搞清楚三件事(问教务处或辅导员):本校绩点怎么算(算不算体育/选修)、加分政策、转专业/推免的相关绩点要求。

## 保研(推免)时间线

面向「推荐免试研究生」,不用考研。核心是**大三下学期开始决定命运**:

| 时间 | 动作 |
|---|---|
| 大一~大二 | 刷绩点排名(最硬的门槛),过四六级,进组/参加竞赛 |
| 大三上 | 确保综测加分材料齐全(竞赛、论文、专利) |
| 大三下 3-5 月 | 准备简历、联系导师(套磁),盯目标院校研招网通知 |
| 大三暑假 5-7 月 | **夏令营**(保研第一轮主战场,线上+线下都有,多投多试) |
| 大四上 9 月 | **预推免**(第二轮机会,错失夏令营者的重要窗口) |
| 9 月末 | 全国推免系统正式确认志愿(唯一正式录取渠道) |

- 官方系统:中国研究生招生信息网「推免服务系统」<https://yz.chsi.com.cn/tm>
- 信息渠道:目标院校**研究生院官网 + 学院官网**的通知栏,比任何中介快一天
- 保研名额:各校教务处会公布推免细则(绩点占比/加分规则),**研读本校推免文件是保研第一课**

## 考研时间线

| 时间 | 节点 |
|---|---|
| 大三上~寒假 | 确定目标专业与院校(查招生人数、推免占比、报录比) |
| 大三下学期 | 一轮复习(数学/英语/专业课) |
| 10 月 | 研招网报名 <https://yz.chsi.com.cn> |
| 12 月倒数第二个周末 | 初试 |
| 次年 2-3 月 | 出分、国家线 |
| 3-4 月 | 复试 + 调剂(调剂信息也在研招网) |

**信息差要点**:
- 「复试线」不是「国家线」,好学校复试线远高于国家线;查目标院校历年复试名单和平均分更有参考价值
- 有些专业课自命题院校会调整大纲,9 月后的招生简章一定要重读一遍
- 调剂是信息战:研招网调剂系统开放前,很多院校官网会提前发调剂预告

## 转专业

- 多数学校在**大一学年结束后**开放转专业申请,部分学校看高考分、多数看大一绩点排名
- 近年政策放宽:不少学校推出「大类分流」「零门槛转出」(转出无限制,转入有考核),查本校教务处文件
- **想转就早准备**:大一使劲刷绩点 + 搞清目标学院的转入考核(笔试/面试/名额)

## 辅修 / 双学位

- 报名一般在**大二上**,条件多为「已修学分达标 + 绩点要求」
- 含金量看学校:本校辅修证 vs 辅修学位(学信网可查的第二学位信息以本校政策为准)
- 适合补留学申请要求的 Second Major,或者跨专业保研/求职

## 出国交换 / 公派

- **校际交换项目**:找本校国际处官网,2+2 / 3+1+1 / 学期交换,部分免学费或互免
- **国家留学基金委(CSC)公派**:本科插班生、硕士博士全额资助,官方 <https://www.csc.edu.cn>,看「选拔办法」与自己学校的合作渠道
- 大一就想出国的,先把** GPA + 语言成绩(雅思/托福)「攒」着**,大二大三看项目出手

## 辅导员 / 教务处不会主动告诉你,但值得去问的事

1. 本专业近 3 年**保研率**和去向(可推算你需要的排名)
2. 推免细则文件(加分怎么算、哪些竞赛本校认)
3. 课程学分互认政策（交换 / 暑校学分能不能算）
4. 辅修、双学位、转专业的历年申请通过率
5. 学校「专项推免」名额(支教团、国防专项等少见渠道)
