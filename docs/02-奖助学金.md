# 02 · 奖助学金

> **适用**:全国本专科学生(金额为近年政策标准,每年 7-9 月全国统一部署,以全国学生资助管理中心/本校资助文件为准)
> **核实时间**:2026-10

一句话:**助学金别不好意思申请,奖学金要懂的「怎么被看见」。**

## 体系速览(从多到少)

| 类型 | 大致额度 | 关键词 |
|---|---|---|
| 国家奖学金 | 本专科 1 万/年(2024 学年起提标扩面) | 同专业最硬核的竞争,名额极少 |
| 国家励志奖学金 | 6000/年 | 必须是「家庭经济困难认定」学生 |
| 国家助学金 | 平均 3700/年左右,分档发放 | 只要认定通过就能覆盖多数人 |
| 国家助学贷款 | 本专科最高 1.6 万/年(2023 年提高),研究生 2 万 | 在校利息财政贴,毕业后偿还 |
| 校内/企业奖学金 | 数百~数万不等 | 名目多、竞争池小,大量人不知道 |
| 学费减免 / 绿色通道 | 视家庭情况 | 入学报到时就有,不申请就没有 |

- 政策源头:全国学生资助管理中心(教育部直属),政策解读看他们的官方公众号「中国学生资助」
- 个人信息/贷款/资助记录查询:学信网 <https://www.chsi.com.cn>

## 隐藏的信息差

### 1. 家庭经济困难认定 ≠ 卑微

- 认定走「个人申请 + 民主评议 + 学校审核」,**不再要求当众诉苦**,更别听「家里有条件就别申请,给真正需要的同学」——按政策如实申请是学生的**正当权利**
- 认定通过后,才解锁励志奖学金、国家助学金、多数校内资助和「绿色通道」

### 2. 助学贷款当时看着吓人,其实是甜的

- 在校期间利息由财政全额贴息,毕业后才开始还,且有还本宽限期
- **当年被妖魔化的「校园贷」和国家助学贷款是两回事**,后者是光明正大的正规金融工具
- 办理渠道:国家开发银行学生在线系统 + 县级资助中心,秋季开学前办

### 3. 校内奖学金是「捡漏」大户

- 学校自设的奖学金名目极多:单项奖学金、专项(文体/实践/志愿)、企业冠名奖学金
- **竞争池只有本院系甚至本专业**,了解「细则中怎么加分」远比堆努力重要
- 开学后**找辅导员/往届学长要一份「本校奖助学金评定细则」**,里面有加分项清单(竞赛、论文、志愿服务、学生工作各占多少)

### 4. 评奖评优的「可见性」

- 评奖学金看材料,而材料靠「平时留痕」:竞赛证书、志愿服务时长、学生工作聘书、媒体报道
- 学期末整理一页「成就清单 PDF」,提交材料时完整齐全,不会因漏交而吃亏

### 5. 请不要乱信「代办奖学金」「内部名额」

- 任何声称**交钱就能办下来**奖助学金/助学贷款的,100% 是诈骗
- 助学金和贷款的所有官方流程都**不收任何费用**

## 申请材料清单(春季/秋季)

1. 高校学生及其家庭情况调查表(电子学籍系统生成)
2. 家庭经济困难认定申请表(民政/乡村振兴等部门信息核对已简化)
3. 成绩单与排名证明(教务处开具)
4. 获奖证书、志愿服务证明复印件

## 最容易吃亏的四类人

1. **不好意思申请助学金**的人 → 白白让出每年几千块
2. **不知道「认定」是前置条件**的人 → 励志奖学金资格都没有
3. **只顾绩点不懂细则**的人 → 综测加分长期空白，排名吃亏
4. **材料不留痕**的人 → 学期末想加分找不到证据
