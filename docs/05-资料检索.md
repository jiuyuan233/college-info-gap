# 05 · 资料检索

> **适用**:全体学生
> **核实时间**:2026-10

会检索的人 = 拥有一所免费的名校。这些入口和技巧,直接决定你查资料的速度和视野。

## 第一课:先利用好「你交学费买到的」资源

很多人四年都没打开过学校图书馆官网,而这些是**付费给你的**:

- **学术数据库**:知网、万方、Web of Science、IEEE 等,校内 IP 或学校 VPN/图书馆账号免费用
- **校外访问**:很多学校提供 WebVPN / CARSI(用学号登录就能在任何地方访问数据库)——**问图书馆参考咨询，一天就能搞明白**
- **电子书平台**:学校订购的电子书库、教材库
- **参考咨询**:图书馆员会提供文献检索培训,很多学校还有论文查重的校内免费次数

## 文献管理:从 Day 1 就用 Zotero

- **Zotero** 免费、开源、浏览器一键抓取文献,PDF、笔记、引用样式全自动:<https://www.zotero.org>
- 配合浏览器插件,写论文时引文自动生成(GB/T 7714 样式都有)
- Word/LaTeX/Overleaf 全适配——毕业论文最终会感谢你

## 高效检索的表达式技巧

- 语法速成:`"精确短语"` + `AND / OR / NOT` + `site:` + `filetype:pdf`
- 例:`site:edu.cn 奖学金 评审办法 filetype:pdf` 轻松找到各高校的官方细则 PDF
- 中文政策文件优先找**.gov.cn / .edu.cn 域名**的原文,而不是营销号转述
- 英文:关键词 + site: + filetype: 组合;`inurl:` 也能加速定位

## 信息管理与搜索习惯

1. **收藏夹不如笔记**:用 Obsidian(本地免费)或 Notion,链接+摘录+自己的一句话
2. 学会读官网的**「通知公告」栏目**——高校/院系/政务的大部分硬信息都在通知栏里,而不是搜索引擎首页
3. 邮件订阅或 RSS 订阅关键页面的更新,胜过每天刷手机
4. 所有二手信息(自媒体解读)先找**一手来源**,没有原链接的转述一律存疑
