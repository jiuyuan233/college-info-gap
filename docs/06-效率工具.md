# 06 · 效率工具

> **适用**:全体学生(免费方案优先,时效项目以官方为准)
> **核实时间**:2026-10 ・ GitHub Student Pack / JetBrains 学生权益已核验

工具不在于多,在于你真的用。每个类别选一个写清楚,不要收藏 100 个 app 然后一个不用。

## AI 助手:学习方式的重构

- 国产免费可及:DeepSeek、Kimi、豆包、通义千问等都有免费额度,长文档阅读用 Kimi/DeepSeek 有优势
- **正确的用法**:让它当「苏格拉底老师」(追问我为什么错、给我出题)而不是「答案贩卖机」
- 学术场景可配合官方 API 或各校提供的校内 AI 平台(不少学校已部署合规大模型服务——问信息化办公室)
- ⚠️ **学术诚信**:用 AI 生成课程论文交上去,在多数学校属于学术不端;AI 用来学,不用来代写

## 笔记与知识库

| 工具 | 特点 | 适合 |
|---|---|---|
| **Obsidian** | 本地 Markdown 文件、双向链接、完全免费 | 长期知识库、隐私控 |
| Notion | 数据库+模板生态强大,在线 | 团队协作、项目页 |
| OneNote | 免费、自由书写 | 课堂手写笔记(配合笔) |
| Anki(间隔复习) | 记忆卡片天花板 | 考研/语言/医学 |

- 原则:**笔记是 preemptive 存档**,期末的错题、论文的文献、求职的 STAR 记录,都往同一个系统里丢

## GitHub Student Developer Pack(申请了就是几千刀的资产)

学生认证后免费获得一大包开发者权益,入口:<https://education.github.com/pack>

包含(节选,以官方列表为准):
- **GitHub Copilot(学生版)**:验证学生免费,含无限代码补全(已核验)
- JetBrains 全家桶学生许可(PyCharm/CLion/WebStorm 等全系列 IDE 免费;高校学生可用学信网等证明文件申请)
- 多家云服务商/VPS、域名、设计工具的学生权益

**申请步骤**:Pack 页面点 Get Student Benefits → GitHub 账号开两步验证 → 传学校邮箱(或学生证明材料)→ 一般几天内通过。

## 开发者的学生机/云资源

- 各大云厂商不定期有「高校计划/学生免单」,规则变化频繁,申请前**核对当前活动页**,别硬背经验帖
- 本地开发环境建议:VS Code + WSL 或 Linux,代码版本管理用 Git(先学 add/commit/push/branch 四招)

## 时间管理:一套就够

- **番茄钟**(25 分钟专注+5 分钟休息):手机自带/Forest/物理闹钟
- **周计划**:周日晚 30 分钟列下周 3 个大项+若干小项(别列 20 个任务骗自己)
- 睡前 5 分钟:清空大脑杂念到笔记里

## 学习资料的去中心化渠道(要警惕的部分另见防坑指南)

- 网课质量看**评课社群/本校学长**推荐,不看平台「热门榜首」
- 语言学习:多邻国(入门)+ 原版材料(外刊/播客)进阶
- 打字/办公技能：官方文档（MDN 等一手来源）永远比二手解说视频靠谱

## 一个反常识提醒

> 新工具、新系统带来的「整理感」会骗走学习时间。
> **每学期工具变化不超过一次**,其余时间在既有系统里加内容。
