# 03 · 竞赛指南

> **适用**:本科生与研究生(加分认定最终以**本校推免细则/综测细则**为准)
> **核实时间**:2026-10

竞赛的三重价值:综测加分 → 保研材料 → 简历闪光点。但**绝大多数比赛性价比差别巨大**,选错就是白忙一年。

## 先搞清楚:你的学校认哪些

1. 找本校**推免细则**和**综测细则**(教务处/学院官网),里面有认定的竞赛目录和分值
2. 全国参考:中国高等教育学会每年发布的**全国普通高校大学生竞赛榜单**(收录百项主流赛事)——不在榜单上的「野鸡赛」名校普遍不认
3. 教育部白名单(中小学生竞赛白名单是另一回事,别混淆)

## 主流竞赛速查表

| 竞赛 | 时间节点 | 难度 / 性价比 | 适合谁 |
|---|---|---|---|
| **大创项目**(国家级大学生创新创业训练计划) | 每年 3-4 月院系申报 | 不算比赛但算「科研经历」,保研热捧 | 大一大二想进组、发论文 |
| 数学建模(国赛) | 9 月,3 天鏖战 | 团队 3 人,名校普遍认 | 数学/编程/写作任一强的同学 |
| 数学建模(美赛 MCM/ICM) | 1-2 月 | 国赛的「海外版」,评奖相对宽松 | 想出国、凑科研材料的 |
| 国际大学生创新大赛(原「互联网+」) | 校赛 4-6 月起逐级晋级 | 项目类,要打磨商业计划书和答辩 | 有项目/有资源/会讲故事 |
| 挑战杯 | 两级:课外学术科技作品 / 创业计划 | 学术见真章,创业看孵化 | 大创/实验室成果延伸 |
| 蓝桥杯 | 初赛 4 月 | 程序设计入门级,拿奖相对容易 | 非科班想证明编程能力的 |
| 电子设计竞赛(电赛) | 单数年 8-9 月(省赛)+ 国赛 | 电子/自动化方向含金量高 | 硬件、嵌入式方向 |
| ACM-ICPC / CCPC | 区域赛 10-11 月,前置校赛/网络赛 | 算法竞赛塔尖,认可度极高且公平 | 计算机类专业,越早打越好 |
| 外研社·国才杯英语系列 | 校赛→省赛→国赛 | 英语方向性价比高 | 英语能力不错的所有专业 |
| 其他来路不明的「国际/全国」竞赛 | 随时搜得到 | ⚠️ 交钱买证的居多,先查榜单 | — |

## 选赛策略(性价比思维)

1. **先看本校细则给多少分**:同一比赛在校 A 是推免加分,在校 B 可能只是「参与体验」
2. **保研向** → 榜单内的学术类/专业类赛事 + 大创 + 论文,组合拳
3. **求职向** → 比赛的「故事价值」比奖项等级更重要:你解决了什么问题、用了什么技术
4. **低成本高回报**的套路:大一大二跟学长组队打一两次,熟悉流程;大三做核心贡献者

## 大创申请要点

- 每年**春季**(各校 3-4 月启动)向学院提交申报书,项目分国家级/省级/校级
- **找靠谱指导老师**比想法更重要:老师=资源+经费+改申报书的人
- 结题成果(论文/专利/软著)才是给保研的材料,别只满足于「做了项目」

## 团队与导师

- 组队原则:**互补不重叠**(技术+写作+答辩),**跨年级**(学长带路+自己练手)
- 导师邀请信要礼貌且具体:「我了解您的 XX 方向,我们项目规划是 XX,希望您指导,预计投入每周 X 小时」
- 好导师一句话点透申报书;差导师会把项目拖到结题前一周

## 识别水赛(防坑)

- 特征:报名费高(数百~数千)、获奖比例超过 50%、查无主办方官网、官网像模板站
- 佐证方式:对比高教会竞赛榜单、看往届**获奖公示**是否公开可查、搜「比赛名 + 活动 + 质疑」
- 原则:**正规赛事不收高额报名费**;「交钱买证」的比赛写上简历是负资产
